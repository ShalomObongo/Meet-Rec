# Product Overview

MeetRec is a **local-first AI notepad for meetings** that combines real-time audio recording, transcription, and AI-powered summarization while keeping user data private and secure.

## Core Value Propositions

- **Privacy-First**: All data stays local by default; cloud sync is optional
- **Offline-Capable**: Full functionality without internet connection
- **Real-Time Intelligence**: Live transcription and AI summaries during meetings
- **Flexible Architecture**: Support for both local and cloud AI models

## Key Features

- **Audio Recording**: Flexible source selection (mic only, system audio only, or both) with real-time level monitoring
- **Transcription**: Local models (Whisper, Parakeet) or cloud providers (Deepgram, Groq, Fireworks)
- **AI Summaries**: Transform raw notes into polished summaries using templates
- **Triple-Pane Editor**: Memos (raw notes), Transcript (word-by-word), Summary (AI-enhanced)
- **Calendar Integration**: Sync with Apple Calendar, Google Calendar, Microsoft Outlook
- **Organization**: Folders, tags, timeline view, and full-text search

## Target Users

Remote workers, professionals in sales/consulting/product roles, and teams requiring meeting documentation with privacy guarantees.
